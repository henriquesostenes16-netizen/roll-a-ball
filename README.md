# Roll a Ball — Labirinto ( LINK DO JOGO > https://play.unity.com/en/games/bdd17d4e-8d18-4967-af7d-7c8253bb82bc/roll-a-ball-trabalho)

Jogo 3D no estilo **Roll a Ball** com um mapa em formato de **labirinto**. O jogador controla uma bolinha preta e precisa encontrar e coletar **12 quadradinhos dourados** espalhados pelo cenário para concluir o jogo.

## Objetivo

- Mover a bolinha pelo labirinto, desviando das paredes.
- Coletar os **12 quadradinhos dourados**.
- Ao coletar todos os 12, o jogo é concluído e **reinicia**, voltando ao estado inicial.

## Como jogar

1. Abra o projeto/executável do jogo.
2. Controle a bolinha pelo labirinto (teclado: setas ou WASD).
3. Encoste nos quadradinhos dourados para coletá-los.
4. Acompanhe a pontuação pelo contador **Count** no topo da tela (de 0 a 12).
5. Ao chegar em **Count: 12**, o jogo reinicia.

## Elementos do jogo

| Elemento | Descrição |
|---|---|
| Bolinha | Personagem controlado pelo jogador (esfera preta) |
| Quadradinhos dourados | Itens colecionáveis, 12 no total |
| Paredes | Estrutura do labirinto, que bloqueia o caminho |
| Contador (Count) | Mostra quantos itens já foram coletados |
| Câmera | Visão de cima, acompanhando a bolinha |

## Demonstração

O vídeo `(https://youtu.be/Wgjgz8878aY?is=Lib7ATg6g7J6rb0H)` mostra uma partida: o contador sobe a cada quadradinho coletado, indo de 0 até 10 no trecho gravado.

## Regras resumidas

- Total de itens: **12**
- Condição de vitória: coletar todos os 12
- Ao vencer: o jogo reinicia

Trabalho desenvolvido por **Sostenes**.
